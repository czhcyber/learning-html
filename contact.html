Frequently asked, occasionally

Is this site built with a framework?

No. It is hand-written HTML, one stylesheet and one small JavaScript file. I wanted to understand the platform before reaching for tools that hide it.

Can I reuse the code?

Yes, for learning. The text and the illustrations are mine, so please write your own words and draw your own images rather than copying these.

How is the site hosted?

It is a static site published with GitHub Pages straight from the repository, so every push updates the live address within a minute or two.

Why does the form not send anything?

Because a static host has no server to process it. Rather than pretend, the form validates your input and tells you plainly that no email was sent.
