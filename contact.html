Short-Term Goals

In Progress

📅 Next 1-3 months, I'm working on:

  • Complete JavaScript fundamentals mastery — especially async programming and closures

  • Start learning React and build my first React component
  • Improve this website's performance score (aiming for 90+ on Lighthouse)

Fun Facts About Me

  • 🤖 I named my "Useless Machine" project because it perfectly represents my sense of humor — building something sophisticated that does absolutely nothing is oddly satisfying!
  • ⏰ The Study Timer was born from frustration — I just wanted a simple timer without sign-ups or ads. Sometimes the best projects come from scratching your own itch.
  • ✨ I'm slightly obsessed with smooth animations. If a button doesn't have a satisfying hover effect, is it even a button? (Kidding... mostly.)
  • 🎨 I believe the best websites make users forget they're using a website — when the interface disappears and only the experience remains.
  • 🌱 My goal is to make web development feel less intimidating and more accessible to everyone.
  • 🐛 I've spent hours debugging only to realize I misspelled a variable name. Every. Single. Time.
  • 🎯 When I learn something new, I can't rest until I build something with it. Theory is great, but building cements the knowledge.
